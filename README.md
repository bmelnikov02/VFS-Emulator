# VFS Emulator

## Общее описание

VFS Emulator - графический эмулятор с поддержкой виртуальной файловой системы.
Программа принимает параметры командной строки, выполняет команды пользователя или загруженные из стартового скрипта, отображает историю выполнения в графическом интерфейсе.
Проект реализован на C++ с использованием Qt 6.

## Функции и настройки

- `ls` - вывести содержимое текущего каталога.
- `cd <directory>` - перейти в каталог.
- `cd ..` - перейти в родительский каталог.
- `conf-dump` - выводит текущую конфигурацию эмулятора в формате `ключ=значение`.
- `tree` - вывести дерево виртуальной файловой системы.
- `uptime` - вывести время работы эмулятора.
- `chmod <permissions> <name>` - изменить права объекта в памяти.
- `cp <source> <destination>` - скопировать файл или каталог в памяти.
- `exit` - завершает работу приложения.
- Поддерживается выполнение команд из стартового скрипта.
- Ошибочная команда не останавливает выполнение стартового скрипта.

### Параметры запуска

1. Путь к физическому каталогу VFS.
2. Путь к стартовому скрипту.

## Сборка и запуск

### Требования

- C++17 или новее.
- Qt 6.
- CMake.
- Компилятор MSVC 2022.

### Сборка

Проект открывается в Qt Creator через файл `CMakeLists.txt`.

Для сборки проекта необходимо:

1. Открыть `CMakeLists.txt` в Qt Creator.
2. Выбрать комплект `Desktop Qt 6 MSVC 2022 64-bit`.
3. Выполнить сборку проекта.

### Запуск

Для обычного запуска используется файл:

```text
run.bat
```

## Тестирование

Тестовые сценарии находятся в папке `tests`.

Доступны следующие сценарии:

- `run_normal.bat` - обычный запуск эмулятора с основной тестовой VFS и стартовым скриптом.
- `run_deep.bat` - запуск с многоуровневой VFS. Используется для проверки `cd`, `tree`, рекурсивного копирования каталогов и работы с вложенной структурой.
- `run_second.bat` - запуск с минимальной VFS. Используется для проверки работы с пустым каталогом и ошибочных команд.
- `run_error.bat` - запуск с несуществующим стартовым скриптом. Используется для проверки обработки ошибки открытия файла.

Стартовые скрипты содержат команды, которые автоматически выполняются после запуска приложения.
